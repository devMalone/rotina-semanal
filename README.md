# Organização da Rotina Semanal

Repositório central da sua **Rotina Semanal**, com sincronização direta para o celular.

Link oficial do Web App: **https://devmalone.github.io/rotina-semanal/**

---

## Arquivos Disponíveis

### 1. index.html — Web App Mobile (Oficial)
- **Por que index.html?**: É o arquivo padrão dos servidores web (GitHub Pages). Graças a esse nome, o aplicativo abre direto no link sem precisar digitar nada no final da URL.
- **Recursos**:
  - Live Tracker ("O que fazer agora?"): Identifica a tarefa do momento em tempo real.
  - Navegação por Dia: Segunda a Domingo com nomes diretos e objetivos.
  - Checklist Interativo: Marque o que foi feito com salvamento automático no celular (localStorage).
  - Dark / Light Mode ergonômico.

### 2. rotina_semanal.ics — Calendário com Notificações / Alarmes
- Arquivo iCalendar padrão pronto para importar no **Google Agenda / Celular**.
- Alarmes automáticos configurados para tocar 10 a 15 minutos antes de cada compromisso.

### 3. rotina_semanal.csv — Planilha Estruturada
- Planilha com separador ponto e vírgula (;) e codificação UTF-8 para Excel e Google Planilhas.
